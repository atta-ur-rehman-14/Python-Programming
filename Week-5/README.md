# Nested Loop
A nested loop is a loop inside another loop. The inner loop runs completely every time the outer loop runs.
# Syntax
```
for variable1 in sequence:
    for variable2 in sequence:
        statement
```
# Dictionary 
A dictionary in Python is used to store data in key–value pairs.

👉 Just like a real-life dictionary:

- Word = Key
- Meaning = Value
# Syntax
```
dictionary_name = {
    key1: value1,
    key2: value2,
    key3: value3
}
```
- Important Points
  - Keys must be unique
  - Values can be anything (string, number, list, etc.)
  - Written inside { }
