# Class Management System

A Python desktop application for managing students, classes, enrollments, and attendance with a simple Tkinter user interface.

## Features

- Add, update, and delete students
- Add, update, and delete classes
- Enroll students in classes
- Mark attendance for each enrollment
- View a dashboard summary
- Save all data locally in a JSON file

## Project Files

- `main.py` - application entry point and UI
- `storage.py` - JSON data storage helpers
- `data.json` - local data file created automatically when the app runs

## How to Run

1. Open a terminal in this folder.
2. Run:

```bash
python main.py
```

## Notes

- The app uses only Python standard library modules.
- No external installation is required if Python is already installed.
