# Function
A function in Python is a block of code that performs a specific task and can be reused whenever needed.

### Simple words
A function is like a machine — you give it input, it does some work, and gives you output.

# Why we use functions?
- To avoid repeating code
- To make code easy and clean
- To solve problems step by step
# syntax
```
def function_name(parameters1,parameters2):
    # code block (body of function)
    return value
```
