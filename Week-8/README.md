# Set
A Set in Python is  a bulit-in data type that is used to store multiple values in a single variable.
A set has following Charactristics :
- It is Unordered(item has no fixed Position)
- it does allow duplicate Values
- it is mutable(you can add or remove items)
# match Statement
The match statement in Python is used for pattern matching.
It allows a program to compare a value with multiple cases and execute the matching block of code.

- It works similar to the switch-case statement in other programming languages.

# syntax
```
match variable:
    case value1:
        # code
    case value2:
        # code
    case _:
        # default case
```
# What is an Array?

An array is a data structure used to store multiple values in a single variable.

- In Python, arrays are not built-in like C/C++
- Instead, we usually use:

- Lists (most common)
- Or array module (less common)
