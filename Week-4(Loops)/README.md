# Loops
A loop in Python is a programming structure that is used to repeat a block of code multiple times until a specific condition is met.
### Types of Loops
1. For Loop
A for loop is used when we know how many times the loop will run.
# sntax
```
for variable in sequence:
    statement
```
OR
```
for <temp-variable> in <iterator>:
    <for loop body>
```
2. While Loop
A while loop is used when a block of code needs to run as long as a condition is true.
# Syntax
```
while condition:
    statement
```
# Nested Loop
A nested loop is a loop inside another loop. The inner loop runs completely every time the outer loop runs.
# Syntax
```
for variable1 in sequence:
    for variable2 in sequence:
        statement
```
